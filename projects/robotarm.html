로보틱스 · Physical AI

로봇팔에 VLA 모델을 붙여 사용자 의도를 동작으로 연결했습니다

Project 1

책상정리 Physical AI 에이전트 (경북대 시제품제작 경진대회, 2025.10~12)

MyCobot280과 SO-101 로봇팔에 오픈클로(OpenClaw) 에이전트를 연결해 책상 정리, 책 배치, 물 따르기, 조명 제어 네 가지 태스크를 수행하게 했습니다. 태스크 설계, 동작 순서 구성, 제어 로직 기획, 시제품 제작과 테스트를 맡았고, Octo VLA 로봇팔 적용 기획과 사용자 의도 분석 설계, 작업 시나리오 통합을 담당했습니다.

Project 2

생활쓰레기 수거 로봇팔 (SDGs 소셜벤처 챔피언십 은상, 2025.11)

SAM2를 커스터마이징해 생활쓰레기 6종을 자동 분할하고, ZED Mini의 RGB+Depth를 C++ 포인트클라우드로 변환해 위치와 부피를 추정했습니다. Octo 모델을 6자유도에서 4자유도 구조로 파인튜닝해 로봇팔 수거 동작을 구현했고, 옵토커플러 노이즈 저감과 STM32 모터 명령 구조도 맡았습니다.

Project 3

쓰리봇 VLA 확장 (진행 중)

Isaac Sim에서 기본 행동 데이터를 생성하고 실물 로봇팔로 추가 수집하면서 wrist / overhead / side 세 시점의 행동 궤적을 기록합니다. XY 이동 4축은 MLP로 빠르게 결정하고, 윈치 Z축은 줄이라 흔들림·탄성 때문에 다루기 까다로워 Gaussian Policy로 평균과 불확실성을 함께 예측하게 했습니다. "이 정도 움직이되 이만큼 오차가 있을 수 있다"는 확률적 판단이 필요한 축과 결정적으로 움직여도 되는 축을 구분한 것입니다.

부팅 시 자동으로 Locked 상태에 들어가 AI 모델의 모든 제어 명령을 차단하고, 사용자가 각 축을 리밋 스위치까지 수동으로 이동시킨 뒤 reset_odometry 서비스를 호출해야만 잠금이 풀립니다. 소프트웨어가 인식하는 좌표와 실제 물리 위치가 어긋난 채로 AI가 움직이면 충돌 사고로 이어지기 때문입니다.

원칙 — AI가 예측을 잘못해도 물리적으로 안전한 상태를 시스템 차원에서 보장한다 — 이후 어떤 자동화 시스템을 만들든 재사용하는 설계 철학입니다.
